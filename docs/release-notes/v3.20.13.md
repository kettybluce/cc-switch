# CC Switch v3.20.13

本仓库独立构建。**v3.20.12**（tag `97cbce00`）只含 #42 salvage + #43 Linux 投影夹具。本版从当前 `main`（`f8c2d173` 之后的版本 bump）出包，叠上其后合入的：

- **#45** `96fbdc3c` Wave C：`skillId≠dirname`、Claude 一键套用顺序、豆包展示名 i18n

**请优先使用绿色版（Portable）。** MSI 若出现 Error 5，见 [windows-msi-error-5-zh.md](../windows-msi-error-5-zh.md)。

请从本仓库 v3.20.12（或官方 3.20.2 + 本 fork main）升到本页 v3.20.13。已在 3.20.12 的用户只需本版 Wave C + 夹具/Docker 自测。

## 自测

**发版门禁（自测工作之后）：必须跑 Docker 全量自测并附报告。** 现在默认 `pnpm test:docker` / `pnpm test:docker:all` 都是全量（`TEST_FILTER=all`，容器内完整 `cargo test --manifest-path src-tauri/Cargo.toml`），每次写出 `docs/self-test-reports/docker-self-test-YYYYMMDD-HHMM.md`。报告至少含退出码、通过/失败/忽略计数、失败片段、SCHEMA 18。显式收窄（`proxy` / `pi-crud` / `lib-lite`）**不能**代替全量报告。

云端 Linux / GitHub Actions：`pnpm typecheck` / `format:check` / `test:unit`；`cargo fmt` / `clippy` / 相关 `cargo test`（含 `proxy_projection_linux`、Pi CRUD 夹具）。不写用户 `C:` 数据。

**云端测试 ≠ 真机 Windows / macOS 冒烟。** 没有在用户电脑上走 Claude/Codex/Pi CLI 或 MSI / DMG 安装。Actions `windows-latest` / WSL2 / `macos-latest` 是编译检查，不是装包冒烟。

装上 v3.20.13 后请自己点：

1. skills.sh 目录名与 skillId 不一致的技能应能安装/更新，更新后源路径应是真实目录
2. Claude 表单「应用到所有角色」应按面板顺序套用，默认模型在最后
3. 新建豆包卡显示「火山 豆包AI」（中文）/ Volcengine Doubao（英文）；已有 Pi `cc-switch-dou-bao-seed` 键不被改写
4. Pi 供应商增删改应同步 `~/.pi/agent/models.json`；删当前默认应改派，不应残留孤儿键
5. 出包前必须 `pnpm test:docker`（或 `pnpm test:docker:all`）退出 0 并留下 `docs/self-test-reports/` 全量报告（显式收窄不够）
6. MSI Error 5 → 改用绿色版 zip
7. 账号默认 / Cursor 池模型行为与 3.20.12 相同

任一步 FAIL：把日志贴到 issue。SCHEMA 没升，回退 v3.20.12 / v3.20.11 / 官方 3.20.2 是安全的。
