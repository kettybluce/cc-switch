# CC Switch v3.20.9

本仓库独立构建，基于官方 **3.20.x**（含已合并 PR #37）。只发布 **Windows x64**（MSI + 绿色版）。不构建 Linux / macOS / ARM64。

**请优先使用绿色版（Portable）。** MSI 若在安装/升级时出现 Error 5（拒绝访问 `D:\Config.Msi` 或系统盘 `Config.Msi`），这是 Windows Installer 回滚缓存 ACL，per-user 安装包无法修复。说明见 [windows-msi-error-5-zh.md](../windows-msi-error-5-zh.md)。

**SCHEMA 仍为 18。** 没有 `migrate_v18_to_v19`、没有新表、没有改 `proxy_config` CHECK。官方 3.20.2 仍能打开这个库文件。Pi 接管标志仍是 `settings.proxy_takeover_pi`。

请从本仓库 v3.20.8（或官方 3.20.2 + 本 fork main）升到本页 v3.20.9。

## 修复的问题

- **Pi 拉取模型对齐 Claude（Option A）。** 列表拉取走供应商 URL 或预设 `modelsUrl`（DeepSeek / PPIO / Novita / 国内腾讯 Token Plan 等），**不**改写到 Claude listen `15721`。出站：`global_proxy_url` 有值走全局代理，为空则沿用 Claude（直连 / 系统代理）。聚合商列表默认 Bearer，不把表单 `api` 当成拉取鉴权；`api` 仍写入 `models.json` protocol。空列表恢复「创建」。
- **WSL live `models.json` CRUD 同步。** 权威文件是 `get_pi_agent_dir()/models.json`（`.pi` 根规范化为 `.pi/agent`）。`pi_config_dir` 优先；未设置且 Claude/Codex 已是 WSL UNC home 时，用同一发行版 `~/.pi/agent`。添加（默认 live）/ 更新（仅当已在 live）/ 删除 / 移除原子更新 provider 节点，保留未知字段，**不碰** `auth.json`。live 删除/更新后刷新或作废整文件接管备份，关闭接管时不会把已删节点还原回来。仅当旧文件已存在时镜像 `~/.pi/models.json`。
- **Pi 默认供应商。** 卡片「设为默认」写 `settings.json` 的 `defaultProvider` 与合理 `defaultModel`（该节点第一个模型 ID），保留未知字段。高亮走 `piCurrentState.defaultProviderId`，不用 Claude `currentProviderId`。删除或移除当前默认时，同一次写入改派到另一个仍启用节点；没有其他启用项则清除。

## 优化

- **SCHEMA 18，可切回官方。** 无库迁移。无 `proxy_config` 行 `app_type='pi'`。
- **Windows-only 打包。** 与 v3.20.8 相同：tag 触发只出 MSI + 绿色版。

任一步 FAIL：把日志贴到 issue。SCHEMA 没升，回退 v3.20.8 / 官方 3.20.2 是安全的。
