# CC Switch v3.20.12

本仓库独立构建。**Wave A + Wave B 已在 v3.20.11**（`de75e456` / PR #41）。本版从当前 `main` 出包，叠上其后合入的：

- **#42** `0e0c2629` salvage：SIGTERM 托盘恢复、Pi `defaultProvider` 愈合、SQLite WAL、`staleTime` 30s、`release.yml` 补 `fi`、phf patches
- **#43** `90e0d3a5` Linux 夹具：覆盖 Pi / Claude / Codex 代理投影

**不是官方 3.20.3 / 3.20.12。** 没有整段合并官方 `main`，没有采用官方版本号。发布 **Windows x64**（绿色版优先，MSI 次要）与 **macOS**（`.dmg` / `.zip`；有 Apple 证书时签名公证，否则为未签名包）。不构建 Linux / Windows ARM64。

**请优先使用绿色版（Portable）。** MSI 若出现 Error 5，见 [windows-msi-error-5-zh.md](../windows-msi-error-5-zh.md)。

**SCHEMA 仍为 18。** 没有 `migrate_v18_to_v19`、没有 MiniMax Code（#7383）、没有新表、没有改 `proxy_config` CHECK。官方 3.20.2 仍能打开这个库文件。Pi 接管标志仍是 `settings.proxy_takeover_pi`。账号默认 / **Cursor 池模型**全部保留。

请从本仓库 v3.20.11（或官方 3.20.2 + 本 fork main）升到本页 v3.20.12。已在 3.20.11 的用户只需本版 salvage + Linux 夹具。

## 修复的问题

- **退出残留**：Unix `SIGTERM`/`SIGINT` 走与托盘退出相同的 Live 恢复；有主窗口时的 `ExitRequested(code=None)` 按用户退出清理
- **Pi 孤儿供应商**：`models.json` 同步时愈合 DB `is_current` 与 live `defaultProvider` 不一致（如 `fd`/`flz`）
- **发版工作流**：补回 `Detect Apple signing secrets` 步骤缺失的 `fi`
- **macOS 构建**：本地 `phf` / `phf_macros` patch，绕过现代 rustc 下 `proc_macro_hack` 失败；`strip=false` 避免 macOS 27 linker 损坏 proc-macro dylib

## 优化

- SQLite **WAL** + `busy_timeout` + `synchronous=NORMAL`
- 前端默认 `staleTime` 30s，减少窗口回焦 IPC 风暴
- **#43** Linux 云端夹具：把 Pi `models.json` 与 Claude/Codex live 设置投影到共享 listen，关闭接管时恢复
- **SCHEMA 18，可切回官方。** 无库迁移。Pi UNC、共享 Claude listen 接管、`x-cc-switch-app: pi`、1214 remap、Pi CRUD↔`models.json`、默认供应商、拉取模型 Option A、会话仪表盘、账号默认 / Cursor 池模型全部保留
- **Wave A+B 已在 3.20.11**，本版不再重复列出 npm dist-tags / 提示词刷新 / 技能归档上限 / Kimi Global / CodexLiveAuthSwitchGuard / OpenCode 批量加模型 / apikey.fan / Fable 周限额
- **刻意跳过：** #7383 SCHEMA 19 / MiniMax Code、官方版本号 / 整段合并官方 main

## 自测

云端 Linux / GitHub Actions：`pnpm typecheck` / `format:check` / `test:unit`；`cargo fmt` / `clippy` / 相关 `cargo test`（含 `proxy_projection_linux`）。不写用户 `C:` 数据。

**云端测试 ≠ 真机 Windows / macOS 冒烟。** 没有在用户电脑上走 Claude/Codex/Pi CLI 或 MSI / DMG 安装。Actions `windows-latest` / WSL2 / `macos-latest` 是编译检查，不是装包冒烟。

装上 v3.20.12 后请自己点：

1. Unix 下 `kill`/关窗后 Live 配置应恢复，不应残留接管
2. Pi 当前供应商应跟随 live `defaultProvider`，不应停在已删除的 `fd` 等孤儿键
3. 窗口回焦时 IPC 应比 3.20.11 更少（`staleTime` 30s）
4. MSI Error 5 → 改用绿色版 zip
5. 账号默认 / Cursor 池模型行为与 3.20.11 相同

任一步 FAIL：把日志贴到 issue。SCHEMA 没升，回退 v3.20.11 / 官方 3.20.2 是安全的。
