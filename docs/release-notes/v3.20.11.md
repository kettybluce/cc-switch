## 自测

云端 Linux / GitHub Actions：`pnpm typecheck` / `format:check` / `test:unit`；`cargo fmt` / `clippy` / 相关 `cargo test`。不写用户 `C:` 数据。

**云端测试 ≠ 真机 Windows 冒烟。** 没有在用户电脑上走 Claude/Codex/Pi CLI 或 MSI 安装。Actions `windows-latest` / WSL2 是 cargo 检查，不是装包冒烟。

装上 v3.20.11 后请自己点：

1. 设置 → 关于里刷新工具版本，Codex/OpenCode/OpenClaw 卡片不应再卡「加载中」数分钟
2. 外部编辑 `CLAUDE.md` / `AGENTS.md` 后打开提示词面板或切回窗口，已启用条目应更新；Pi 提示词 CRUD 行为不变
3. 安装条目很多的技能仓库（如 ppt-master 整仓归档）不应再报 `ARCHIVE_TOO_MANY_ENTRIES`
4. 新建卡可见 Kimi Global / Kimi For Coding Global；已有 Pi `models.json` 键不被改写
5. 删除托管 ChatGPT 账号再登录后，接管/切换/恢复应能重新绑定，不应永久失败
6. OpenCode 表单「获取模型」后可搜索并勾选批量添加
7. 新卡 APIKEY.FUN 默认走 apikey.fan，旧 `.fun` 仍可作为候选
8. Claude 卡片与托盘能单独显示 Fable 周限额
9. 退出后 Codex/Gemini 重试与超时不被 Claude 覆盖；Pi 接管仍共享 Claude listen
10. MSI Error 5 → 改用绿色版 zip

任一步 FAIL：把日志贴到 issue。SCHEMA 没升，回退 v3.20.10 / 官方 3.20.2 是安全的。
