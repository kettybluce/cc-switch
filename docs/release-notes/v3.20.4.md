# CC Switch v3.20.4

本仓库独立构建，基于官方 **3.20.x**（含已合并 PR #27）。只发布 **Windows x64**（MSI + 绿色版）。不构建 Linux / macOS / ARM64。

**请优先使用绿色版（Portable）。** MSI 若在安装/升级时出现 Error 5（拒绝访问 `D:\Config.Msi` 或系统盘 `Config.Msi`），这是 Windows Installer 回滚缓存 ACL，per-user 安装包无法修复。说明见 [windows-msi-error-5-zh.md](../windows-msi-error-5-zh.md)。

**SCHEMA 仍为 18。** 没有 `migrate_v18_to_v19`、没有新表、没有改 `proxy_config` CHECK、没有独立 Pi 网关。官方 3.20.2 仍能打开这个库文件。

请从本仓库 v3.20.3（或官方 3.20.2 + 本 fork main）升到本页 v3.20.4。

## 修复的问题

- **Claude 配成 `\\wsl.localhost\…\.claude` 时 About 卡显示 Win，而不是 WSL。** 徽章仍走官方 override 路径（不是 PATH 上有没有 Windows 二进制）。UNC / `\\?\UNC\` / 正斜杠现在都能解析出发行版，卡上显示 **WSL · \<distro\>**，与 Pi 一致。
- **Pi 供应商页没有「使用统计」入口，或被本地代理接管开关藏起来。** 顶栏柱状图按钮对 Pi（以及同套用量面板的应用）**始终可见**，不跟接管。点一下进入设置 → 用量；从 Pi 点入会预选 Pi 筛选。
- **Pi 会话列表/刷新对不上 WSL 里的 JSONL。** 根目录是 `\\wsl.localhost\…\home\<user>\.pi\agent\sessions`。若设置指到 `.pi` 会落到 `.pi/agent`。没有 C: `pi-wsl-sessions` 镜像。
- **用量统计看不到 Pi。** 会话 JSONL 扫描仍写 `app_type=pi`。走共享 Claude listen 的代理请求通过投影进 `models.json` 的 `x-cc-switch-app: pi` 记入现有 `proxy_request_logs`（出站会剥掉该头），用量页可筛 Pi。不 bump SCHEMA，不插 `proxy_config` 的 `pi` 行。
- **Pi 本地代理要对齐 Claude。** 继续 #25：`~/.pi/agent/models.json` 投影到现有 Claude listen（`0.0.0.0` → `127.0.0.1`），同一端口，无 `/pi/` 前缀。不写 `defaultProvider` / `defaultModel`，不碰 `auth.json`。
- **MSI Error 5。** 与官方相同的 per-user WiX（`InstallPrivileges=limited`）改不了 `Config.Msi` ACL。**先用绿色版。**

## 优化

- **SCHEMA 18，可切回官方。** 用量归因不改 `proxy_config` CHECK。
- **Windows-only 打包。** 与 v3.20.3 相同：tag 触发只出 MSI + 绿色版。
- 安装手册 / README 中文增加 Error 5 → Portable 入口。

云端 Linux 另记：`pnpm typecheck` / `pnpm format:check` / `pnpm test:unit`（135 文件 / 1094 用例）；`cargo fmt --check` / `cargo clippy -- -D warnings`；映射 `cargo test --lib`（徽章路径字符串、`.pi`→`agent/sessions`、投影 header、`pi_takeover_projects_*` 且 `SCHEMA_VERSION == 18`）。

**云端测试 ≠ 真机 Windows 冒烟。** 没有在用户电脑上点过 About 徽章、Pi 会话列表或 MSI 安装。Actions `windows-latest` / WSL2 是 cargo 检查，不是装包冒烟。

装上 v3.20.4 后请自己点：

1. Claude 配置目录设为 `\\wsl.localhost\<发行版>\home\<用户>\.claude` → 设置 → 关于，Claude 卡应为 **WSL · 发行版**
2. Pi 页（接管关着）标题栏仍有柱状图，点进用量，可筛 Pi
3. Pi 会话列表刷新来自 `…\.pi\agent\sessions`，不要出现 C: 镜像目录
4. 打开 Pi 接管发请求，用量里能看到 Pi；关掉接管后 `auth.json` / defaults 不变
5. MSI Error 5 → 改用绿色版 zip，解压运行 `CC-Switch.exe`

任一步 FAIL：把日志贴到 issue。SCHEMA 没升，回退 v3.20.3 / 官方 3.20.2 是安全的。
